Based on the prototype, here is a description of **Landmark-First Pickup**:

### What it is

It is an interactive prototype designed to fix the "last 50 meters" ride-hailing problem in Dhaka, Bangladesh.

### The Problem It Solves

When a ride is booked, the GPS pin often drops on a main road (such as "Road 11"). However, the rider is actually waiting inside a gated compound or around the block, causing drivers to head to the wrong entrance or side.

### How the Prototype Works (Step-by-Step)

1. **Ride Matched:** The ride is confirmed, and the GPS pin drops on the main road while the rider is inside a gated compound.


2. **Add a Landmark:** The app prompts the rider ("Hard place to find? Tell Rahim which gate you’re at") to pick specific details so the driver can navigate directly to them:


* **Which entrance?** Main gate, Back gate, or Side gate.


* **What's nearby?** Options include a gated community, narrow alley, behind a building, near a mosque, near a super shop, or a guard at the gate.


* **Voice Note:** An optional feature allowing the rider to record a short voice note for the driver (Rahim).




3. **Pin Moves to the Gate:** Once the landmark details are selected, the pin updates to the precise gate location.
4. **Driver's Screen:** The driver receives the updated pickup instructions along with any voice notes or landmark details, ensuring a seamless pickup.
